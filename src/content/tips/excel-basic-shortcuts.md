Excelでの作業は、マウスでセルをクリックして…という動きの繰り返しになりがちです。キーボードだけで完結できる操作を覚えると、入力のテンポが大きく変わります。

## まず覚えたい5つ

| 操作 | キー |
|---|---|
| セルを選んだ状態で合計を出す | `Alt` + `Shift` + `=` |
| 今日の日付を入力 | `Ctrl` + `;`（セミコロン） |
| 選んだセルをコピー | `Ctrl` + `C` |
| 1つ下のセルの内容をコピー | `Ctrl` + `D` |
| 保存する | `Ctrl` + `S` |

## よくある使い方

- **月末の集計で `Alt` + `Shift` + `=`**：合計したい数字の下（または右）のセルを選んで押すと、自動でSUM関数が入り合計が出ます。
- **日報や日付入力で `Ctrl` + `;`**：わざわざ今日の日付を打ち込まなくても、その場でパソコンの今日の日付が入力されます。
- **同じ数式を下のセルにもコピーしたいとき `Ctrl` + `D`**：数式が入ったセルの下に、コピーしたいセルまで選択してから押すと、一気にコピーできます。

## 補足

- 保存はこまめに（`Ctrl` + `S`）。停電やアプリの強制終了で作業が消えるのを防げます。
- ショートカットは日本語入力がオンのままでも動作します。
