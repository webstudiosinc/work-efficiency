Wordで文書を作っていると、「文字がなぜか大きい」「コピーしたら書式が崩れた」といった困りごとがよく起こります。基本操作を知っておくと、こうした場面で焦らずに対処できます。

## まず覚えたい5つ

| 操作 | キー |
|---|---|
| 太字にする | `Ctrl` + `B` |
| 下線を引く | `Ctrl` + `U` |
| 文字の書式をすべて解除する | `Ctrl` + `Space` |
| 中央揃えにする | `Ctrl` + `E` |
| 印刷イメージを確認する | `Ctrl` + `P` |

## よくある使い方

- **他の文書からコピーした文字がおかしな書式になったら `Ctrl` + `Space`**：選択した文字の書式（フォントや色など）だけを解除して、周囲の文章と統一できます。
- **タイトルを目立たせたいとき `Ctrl` + `E`**：見出しなどを中央に配置する際、マウスで揃えるより早く整います。
- **印刷前に必ず `Ctrl` + `P`**：印刷イメージを画面で確認してから印刷すると、用紙のムダや体裁崩れを防げます。

## 補足

- コピー＆貼り付け時に「貼り付けのオプション」（貼り付け直後に出る小さいアイコン）から「テキストのみ保持」を選ぶと、書式の崩れを防げます。
- 保存は `Ctrl` + `S` でこまめに行いましょう。
