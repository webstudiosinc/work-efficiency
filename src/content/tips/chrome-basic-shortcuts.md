Webサイトを見ながら仕事をする時間は意外と長いものです。Chromeの操作を少し知っておくだけで、「あっ」となる場面を減らせます。

## まず覚えたい5つ

| 操作 | キー |
|---|---|
| 閉じたタブを復活させる | `Ctrl` + `Shift` + `T` |
| 新しいタブを開く | `Ctrl` + `T` |
| 今のタブを閉じる | `Ctrl` + `W` |
| ページ内を検索する | `Ctrl` + `F` |
| アドレスバーにカーソルを移す | `Ctrl` + `L` |

## よくある使い方

- **間違えてタブを閉じてしまったら `Ctrl` + `Shift` + `T`**：直前に閉じたタブがそのまま復活します。何度も押すと、さかのぼって復活できます。
- **長いページで特定の言葉を探したいとき `Ctrl` + `F`**：ページ内に検索窓が出るので、探したい単語を打つとハイライトしてくれます。
- **URLを打ちたい・検索したいとき `Ctrl` + `L`**：マウスでアドレスバーをクリックしなくても、キーボードだけでカーソルを移動できます。

## 補足

- 「閉じたタブの復活」は、ブラウザを再起動した直後でも使える場合があります。
- 会社のパソコンでChrome以外（Edgeなど）を使っている場合も、多くのショートカットは共通しています。
