社内資料や提案資料の作成でよく使うPowerPointですが、「1枚ずつ手作業で調整している」という方も多いのではないでしょうか。いくつかの操作を覚えるだけで、作業時間が大きく変わります。

## まず覚えたい5つ

| 操作 | キー・操作 |
|---|---|
| スライドを複製する | スライド一覧で `Ctrl` + `D` |
| オブジェクトをまっすぐ移動する | 図形をドラッグしながら `Shift` を押す |
| 図形やテキストを複製する | `Ctrl` + `D`（図形選択時） |
| スライドショーを開始する | `F5` |
| 現在のスライドから再生する | `Shift` + `F5` |

## よくある使い方

- **似たレイアウトのスライドを作りたいとき `Ctrl` + `D`**：1から作り直すより、既存スライドを複製して文字だけ差し替える方が圧倒的に速く、デザインも揃います。
- **図形を水平・垂直にまっすぐ動かしたいとき `Shift` を押しながらドラッグ**：斜めにズレる心配がなく、きれいに整列できます。
- **会議中に途中のスライドから発表したいとき `Shift` + `F5`**：最初からではなく、今開いているスライドからそのまま発表を始められます。

## 補足

- 図形の位置を揃えたいときは、複数選択してから「配置」メニューの「左揃え」「上下中央揃え」などを使うと、手作業より正確に揃います。
- 文字サイズや色を毎回変えるより、最初にテンプレート（スライドマスター）を整えておくと、後の修正が減ります。
