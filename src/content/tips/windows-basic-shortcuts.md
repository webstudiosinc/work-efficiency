パソコン作業のほとんどは「マウスでクリック」でもできますが、キーボードのショートカットを2〜3個覚えるだけで、日々の作業時間が目に見えて減ります。まずは以下の5つから覚えてみてください。

## まず覚えたい5つ

| 操作 | キー |
|---|---|
| 元に戻す | `Ctrl` + `Z` |
| やり直す | `Ctrl` + `Y` |
| ウィンドウを閉じる | `Ctrl` + `W` |
| デスクトップを表示する | `Windows` + `D` |
| ウィンドウを切り替える | `Alt` + `Tab` |

## よくある使い方

- **「あ、間違えた」と思ったら `Ctrl` + `Z`**：ファイルの操作やExcel・Wordの編集で、間違えて削除・変更してしまってもすぐ元に戻せます。
- **会議中に画面を隠したいとき `Windows` + `D`**：開いているウィンドウを一時的にすべて隠して、デスクトップだけを表示できます。もう一度押すと元に戻ります。
- **たくさんウィンドウを開いているとき `Alt` + `Tab`**：押しっぱなしにすると切り替え候補が表示されるので、目的のウィンドウを選んで指を離します。

## 補足

- 機種やキーボードによっては `Windows` キーが図柄（田のようなマーク）だけの場合があります。
- ショートカットは「覚えている分だけ」使えば十分です。全部を一度に覚える必要はありません。
